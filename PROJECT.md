# PROJECT.md
Цель: свой iOS-раннер Windows-игр на базе форка Madeira (GPL-3.0) плюс профили под отдельные игры.
Первая игра: Pathologic 3 (GOG, Unity 6000.2.6f2, Mono, HDRP, шейдеры D3D11).
Устройство: iPhone 16 Pro Max, iOS 26.6.2. Установка через SideStore, JIT доступен.

ПРАВИЛА
- Игровые файлы никогда не попадают в Git (см. .gitignore). Игра на ПК, на телефон идёт отдельно.
- Исходники upstream (willfaust/Madeira) без моего согласования не менять.
- Каждый вывод подкрепляй логом или файлом. Не утверждай непроверенного.
- Одна и та же ошибка 3 раза подряд: остановись, покажи хвост лога и гипотезу.
- Работай в ветке, в main только после моего подтверждения.
- После каждого запуска обнови STATUS.md.

ВЕХИ (каждая проверяется результатом)
M1 Сборка .ipa в Actions проходит, артефакт скачивается.
M2 Установка через SideStore, в настройках JIT и Memory+ зелёные.
M3 Подробные логи Wine/FEX/DXMT лежат в папке, доступной из «Файлов».
M4 Pathologic 3 доходит до главного меню (или чёткая причина, почему нет).
M5 Режим одной игры: запуск по профилю (JSON), без библиотеки.

Remote upstream = willfaust/Madeira. Важные ветки и теги: main = последнее рабочее.
